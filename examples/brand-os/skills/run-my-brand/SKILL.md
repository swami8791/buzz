# Run my brand

This is a conversation. It is not a state machine.

## Gate 1 — What should we talk about?

User: `Run my brand`

Brand OS:

1. Search Notion for stories, projects, old predictions, product lessons, talks, and current work.
2. Read `knowledge/EXISTING.md` so proposed topics are not already drafted.
3. Read `knowledge/POSITIONING.md` so the slate has range (building, operating, proof, perspective) without a Content Director agent.
4. Pull current relevant information (timely public context; RobinReach analytics if the tool is available — as signal, not as an analyst agent).
5. Return **about 5** numbered topic options.
6. Stop.

User replies with numbers: `2, 3, 5`

That reply is the entire Gate 1 mechanism. Do not confirm with a second form. Do not ask for pillar labels. Start Researcher on those numbers.

### Topic quality

Each option should be a sentence a founder would actually say. Prefer tension, a mistake, a then-vs-now, or a belief that costs something. Skip generic "N lessons from shipping AI" unless the lesson is specific and sourced.

## After numbers (not a gate)

For each selected topic: Researcher → Writer → Editor → unpublished RobinReach draft.

If Editor says `revise`, Writer revises once. Then either draft or tell the user what is blocked. Do not add a claims/approval gate.

## Gate 2 — Should this actually go live?

After drafts exist, Brand OS lists RobinReach IDs and waits.

User: `Publish {id} tomorrow at 8 AM`

Schedule or publish **only that id**. Other drafts stay drafts.

If the user says `Run my brand` again later, run Gate 1 again. Do not auto-publish leftover drafts.
